# Omar Qadarah — Personal Portfolio

A responsive personal portfolio website designed and developed to showcase my skills, projects, background, and ways to connect with me.

The website combines a clean, minimal interface with subtle animations, responsive layouts, and a light/dark visual experience. The design was developed from an initial **wireframe** and refined through a **high-fidelity mockup** before being implemented using HTML5 and CSS3.

---

## ✨ Overview

This portfolio represents my journey as a web developer and provides a simple way for visitors to:

* Learn more about me and my background
* Explore my work and upcoming projects
* Understand my approach to creating digital experiences
* Get in touch through the contact section
* Access my professional contact information and GitHub

The main goal was to create an interface that feels **simple, approachable, personal, and human** rather than overly corporate or complicated.

---

## 🎨 Design Process

The website was developed through a three-stage design process:

### 1. Wireframe

The wireframe was used to establish the overall structure and information hierarchy before focusing on colors, typography, imagery, and visual details.

The main layout was organized into:

* Navigation / Header
* Hero section
* Personal statement
* Work / Projects section
* About section
* Contact section
* Footer

### 2. Mockup

The high-fidelity mockup was then used to establish the website's visual identity, including:

* Color palette
* Typography
* Spacing
* Cards
* Buttons
* Imagery
* Form styling
* Light and dark visual themes

### 3. Development

The final design was translated into semantic HTML5 and CSS3 while adding responsive behavior and interactive visual effects.

## 🎨 Visual Design

The visual identity combines a neutral background with purple and warm accent colors.

### Primary Colors

| Purpose           | Color     |
| ----------------- | --------- |
| Secondary / Brand | `#6C5CE7` |
| Light Background  | `#F4F4F8` |
| Dark Background   | `#0D0D1A` |
| Light Text        | `#111111` |
| Dark Text         | `#F5F5F5` |
| Light Cards       | `#FFFFFF` |
| Dark Cards        | `#1C1C1C` |

The CSS organizes these values as custom properties, making the visual system easier to maintain and modify.

---

## 🌙 Light & Dark Themes

The design supports different visual appearances through CSS color variables.

The color system separates:

* Background colors
* Text colors
* Card colors
* Borders
* Shadows
* Form surfaces
* Accent colors

This allows the interface to maintain visual consistency across different themes.

---

## 📱 Responsive Design

The website is designed to adapt to different screen sizes.

Responsive breakpoints are included for:

* Desktop
* Tablet
* Mobile

On smaller screens:

* The hero layout changes from horizontal to vertical
* Images and forms become fluid
* Project cards change from a two-column layout to a single column
* Navigation wraps when necessary
* Footer content becomes vertically stacked
* Decorative elements are hidden when appropriate

These changes are implemented using CSS media queries.

---

## ✨ Animations & Interactions

Subtle animations are used to make the interface feel more dynamic without distracting from the content.

Current effects include:

* Hero fade-in animation
* Floating decorative orb
* Card hover scaling
* Border and background transitions
* Button hover effects
* Animated waving hand

The animations are implemented entirely with CSS `@keyframes`, transitions, and transforms.

## 🚀 Getting Started

No frameworks, package managers, or build tools are required.

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

Navigate to the project directory:

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` directly in your browser.

Alternatively, use a local development server such as the **Live Server** extension in Visual Studio Code.
